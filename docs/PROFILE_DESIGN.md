# Profile design and animation notes

## Direction

The reading order is a wide sunset-lake cover, centered typing introduction and social badges, four featured projects in a **three-column table**, a full-width solar system in **Tech stack**, tech-logo tiles, contact, and the supplied animated record rack at the bottom. Additional projects fold into a details section.

The footer directly embeds `assets/record-rack.svg`: a hand plays the four project records and the display types an introduction for each one. Its CSS handles reduced-motion viewing. The earlier aquarium and its fish legend have been replaced; reef build notes and measurements below describe archived artwork.

The introduction reads **Hey, I am electrifiedchan**. Its local SVG types character by character in a 7.5-second loop and holds the complete line for 2.7 seconds. Explicit character positions and the cursor use the same 20-pixel grid. The cursor remains visible while typing/deleting and blinks only while paused. Text colors adapt to light/dark mode; reduced motion shows the full text with no cursor animation. The heading's image includes the complete introduction as alt text.

The solar system stays full-size at 832 pixels wide in the skills section. Its CH sun has a moving surface and circular corona. Python and TypeScript, the two innermost planets, orbit twice per 21.6-second loop; the outer four orbit once. The asteroid belt uses `Random(11)`, jittered positions, two shades, and small rock silhouettes. The comet enters and leaves beyond the frame during phase .30–.62 with a ramped trail and a softly twinkling four-point glare. The glare uses eight integer cycles per loop. Planet sizes and highlights provide depth cues. These visuals are decorative, not repository statistics.

The README uses repository-hosted images, so its appearance does not depend on a badge or animation service. Every scene has a `<picture>` element that selects its matching `*-static.png` for browsers that support the reduced-motion media preference; GIFs are the default.

The CH mark is rendered into the solar scene from `assets/avatar-source.png`; that PNG remains a required input. The unused standalone logo GIF, still PNG, and generator have been removed. The account's sidebar avatar is a separate GitHub setting.

## Sunset and reef references

- **[Sunset-lake pixel-art reference on GIPHY](https://giphy.com/gifs/xWMPYx55WNhX136T0V)** — warm orange clouds, a golden sun, a lake reflection, and dark foreground reeds. The wide recreation adds visible warm glare, cloud parallax, shifting reflections, and a three-bird flock.
- **[Blue pixel puffer-fish reference on Pinterest](https://in.pinterest.com/pin/781022760377747642/)** — the reference for round bodies, oversized eyes, white bellies, blue fins, and pink lips. The aquarium uses newly drawn sprites with project-specific palettes.
- **[Coral and aquatic plants reference on Pinterest](https://in.pinterest.com/pin/575334921160802851/)** — the reference for branching red coral, hollow purple tube sponges, turquoise foliage, and a golden starfish. A large original anchor and chain, shells, and a broken wooden hull complete the seabed.
- **[Lucide's four-point sparkle](https://lucide.dev/icons/sparkle)** — visual reference for the comet's four-sided glare. The comet is drawn as original pixel geometry; no external icon is embedded.

The footer is **The Project Reef**, an open-water scene with light shafts, distant fish silhouettes, a sandy clearing, and overlapping foreground plants. The blue, violet, mint, and gold inhabitants identify G.U.A.R.D., GitReal, TeamTruth, and ExamHub. Their colors are keyed by a small legend rather than separate exhibit stations.

There are four distinct fish designs: a round blue puffer, a tall purple striped reef fish, slender mint schooling tetras, and an orange clownfish.

Fish travel across the full image and continue past its edges. An 84-source-pixel margin ensures that each sprite is entirely off-screen before its next crossing begins. They enter from both sides, with no visible turning, rotation, squeezing, or bouncing. TeamTruth's school shares a route with slight delays. A red crab walks sideways through the middle of the sandy foreground with alternating feet and articulated pincers. Foreground plants and props can occlude passing fish. All behavior is decorative, without invented metrics.

Fin rates are 32/40/48/40 cycles per loop. Kelp uses three background cycles and four foreground cycles, with stronger foreground sway. Crab leg amplitude follows its sideways speed. Eight bubbles rise from fixed props. The chain runs from the top edge to the anchor ring. The puffer briefly inflates when the school passes, and sparse four-cycle caustic flecks animate the sand. Titles use scale 2; a native HTML text legend beneath the reef remains readable on phones.

The sunset has 120 frames and loops in 14.4 seconds at 832 × 288. The reef has 240 frames and loops in 28.8 seconds at 832 × 416. All three active scenes use 120 ms per frame, making playback about 17% slower than the original 100 ms timing. Both use two-times nearest-neighbor enlargement for the same pixel scale as the solar system. The build entry point is `scripts/build_pixel_worlds.py`; the cover is in `scripts/sunset_scene.py` and the reef's scene, sprites, props, and motion live in `scripts/reef_scene.py`.

All frames were decoded and compared with fresh RGB renders using Pillow 12.3.0. A changed pixel means at least one RGB channel differs. Palette error is the per-pixel maximum absolute channel difference on the 0–255 scale, aggregated over every frame.

## Project selection

Descriptions were checked against the current public project READMEs, rather than relying only on repository descriptions, which can lag behind development. The order is an editorial recommendation based on current work and variety, not a popularity ranking.

1. **[G.U.A.R.D.](https://github.com/electrifiedchan/guard-edge-ai-proctoring)** — recent applied-AI work combining interview coaching, computer vision, and a full-stack interface. The current README describes a coach, while the repository name and short description still mention proctoring. The profile avoids claiming that every component operates offline.
2. **[GitReal](https://github.com/electrifiedchan/Git_real)** — AI resume verification against actual code. Corrects the old profile description that called it a version-control implementation.
3. **[TeamTruth](https://github.com/electrifiedchan/TeamTruth)** — AI memory and contradiction detection for team updates. Explicitly labeled an MVP; the profile does not describe planned GitHub webhook integration as an existing feature.
4. **[ExamHub](https://github.com/electrifiedchan/exam-hub-seating-system)** — a concrete data-processing and allocation application that balances the AI projects.

The expandable section keeps two additional projects discoverable:

- **[Namma Yatri](https://github.com/electrifiedchan/namma_yathri)** — its current scope includes React Native, Supabase, and ride-hailing logic, beyond the UI clone described in the old profile.
- **[VTU Performance Analyzer](https://github.com/electrifiedchan/vtu-performance-analyzer)** — its documented backend is Flask, correcting the previous Node.js label.

Suggested GitHub pinned repositories: these same six projects, with the four selected projects first. Pinning is a separate profile setting; editing this README does not change pinned repositories.

## Preview and publish

1. Open the root `README.md` in a Markdown preview to review the layout. Some editors do not support the `<picture>` element; open `assets/solar-system.gif` in a browser to view the motion directly.
2. Publish the updated `README.md` **and the images in `assets/` together** to the `main` branch of `electrifiedchan/electrifiedchan`. The relative paths need those images in the repository.
3. Visit [your profile](https://github.com/electrifiedchan) to check the final GitHub rendering. Check both themes and a narrow window.
4. Use **Customize your pins** on your profile to select and order the suggested repositories.

No GitHub Actions workflow, personal access token, or hosted animation API is needed to display the included artwork.

For asset regeneration and icon credits, see [assets/README.md](../assets/README.md). Edit `WORLDS` in `scripts/build_profile_art.py` to change planet colors and orbits. Edit `FISH_PALETTES`, `swimmer_pose`, or the prop functions in `scripts/reef_scene.py` to customize the reef. Change `REEF_FRAMES` there or `FRAME_MS` in the build script for timing, then rebuild.
